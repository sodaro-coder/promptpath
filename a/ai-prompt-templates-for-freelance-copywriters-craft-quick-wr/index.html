2. Core Elements of a Quick‑Write Prompt

A well‑crafted prompt contains three layers:

  1. Context – Who is the brand, what’s the product, and what tone does the client want?
  2. Goal – What action should the viewer take? (click, sign‑up, purchase, etc.)
  3. Constraints – Platform limits, character counts, brand guidelines, and any required keywords.

Formula:

``` [Context] + [Goal] + [Constraints] → Generate [Ad Type] copy in [Tone] with [Key Benefits]. ```

Example:

``` You are a freelance copywriter for a boutique skincare brand launching a new vitamin‑C serum. The goal is to drive website clicks for a limited‑time 20% discount. Write a Facebook carousel ad (max 125 characters per headline, 30‑word description) in an upbeat, confident tone, highlighting "brightens skin", "reduces dark spots", and "clinically proven". Include a clear CTA: "Shop Now". ```

Feed this directly into ChatGPT, Claude, or any LLM you prefer and you’ll receive a ready‑to‑publish carousel script.

3. Step‑by‑Step Prompt‑Building Process

Step 1: Capture the Brief in a One‑Liner

Ask the client for a single sentence that captures the product, audience, and primary offer. “Our organic protein bars help busy professionals stay energized, with a 10% launch discount.”

Step 2: Choose the Platform & Ad Format

Different platforms have distinct specs. Keep a cheat sheet handy:

| Platform | Format | Max Headline | Max Body | CTA Options | |----------|--------|--------------|----------|-------------| | Facebook | Carousel / Single Image | 125 char | 30 words | Shop Now, Learn More | | Instagram | Story / Reel | 30 char overlay | 2‑3 lines caption | Swipe Up, Link in Bio | | LinkedIn | Sponsored Content | 150 char | 150 words | Register, Download | | TikTok | In‑Feed Video | 100 char overlay | N/A | Shop Now, Learn More |

Step 3: Insert the Prompt Formula

Plug the brief, platform, and constraints into the formula. Use placeholders for variables you’ll replace per client.

Template Example – Facebook Single Image:

``` [Brand] is launching [Product] for [Target Audience]. The offer: [Offer Details]. Write a Facebook single‑image ad (max 125‑character headline, 30‑word body) in a [Tone] tone, emphasizing [Key Benefit #1], [Key Benefit #2], and ending with a CTA: "[CTA Text]". ```

Step 4: Run the Prompt & Review

Generate 3‑5 variations. Choose the strongest, then apply a quick 5‑second sanity check:

  • Does it hit the primary benefit?
  • Is the CTA crystal clear?
  • Does the tone match the brand voice?

If any element feels off, edit the prompt (e.g., add “use playful language”) and regenerate.

Step 5: Add Client‑Specific Tokens (Optional)

For high‑value clients, embed brand‑specific language or taglines to keep the AI consistent.

``` ... incorporate the tagline "Fuel Your Focus" exactly as shown. ```

4. Ready‑to‑Use Prompt Library

Below are five plug‑and‑play prompts you can copy into your favorite AI tool. Replace bracketed sections with client data.

4.1 Facebook Carousel – 3 Slides

``` You are a freelance copywriter for [Brand], promoting [Product] to [Audience]. Goal: drive clicks to a landing page offering [Discount/Bonus]. Write a Facebook carousel ad with three slides. Each slide needs:

  • Headline ≤125 characters
  • Description ≤30 words
  • One benefit per slide (choose from [Benefit A], [Benefit B], [Benefit C])

Tone: [Brand Tone]. End each slide with a short CTA: "Learn More", "Shop Now", or "Get Yours". ```

4.2 Instagram Story – Swipe‑Up

``` Create an Instagram Story ad for [Brand]’s new [Product]. Audience: [Audience]. Offer: [Limited‑time Deal]. Provide:

  • 3 overlay text lines (≤30 characters each)
  • Caption (max 2 sentences) with a clear swipe‑up CTA: "Swipe Up to Save 15%".

Use a vibrant, youthful tone and include an emoji that matches the brand personality. ```

4.3 LinkedIn Sponsored Content – Lead Magnet

``` Write a LinkedIn sponsored post for [Brand] promoting a free [eBook/whitepaper] on [Topic]. Target: [Professional Segment]. Include:

  • Headline ≤150 characters
  • Body ≤150 words
  • CTA button text: "Download Now"

Emphasize credibility (e.g., "Backed by 10+ years of research") and a pain point ("Struggling with X?"). ```

4.4 TikTok In‑Feed Caption

``` Generate a TikTok caption for a 15‑second video showcasing [Product] in action. Audience: Gen Z/young adults. Offer: "First purchase 20% off with code TIKTOK20". Include:

  • Hook (≤10 words)
  • Benefit statement (≤15 words)
  • CTA: "Tap the link in bio"

Tone: playful, trend‑savvy, with one relevant hashtag. ```

4.5 Twitter Promoted Tweet

``` Compose a Twitter promoted tweet for [Brand] announcing a flash sale on [Product]. Include:

  • Hook (≤140 characters)
  • Key benefit (≤2 bullet points)
  • CTA with shortened URL placeholder

Use a conversational tone and add two trending hashtags. ```

Caption: “Your next workout deserves gear that loves the planet as much as you do. Swipe up to claim 25% off EcoFit leggings now!”

Result: Ready for design handoff in under 2 minutes.
